# 电商口播脚本生成器（纯前端Demo）

> 基于商品信息自动生成多风格口播脚本的交互式工具

## 🚀 快速开始

### 方式一：直接打开（推荐）

双击 `index.html` 文件，即可在浏览器中直接使用！

### 方式二：开发环境

```bash
npm install
npm run dev
```

## ✨ 功能特性

- 📥 **智能解析**：支持商品链接/文本/名称自动提取
- 🏷️ **标签管理**：卖点、人群、痛点、场景、促销五类标签
- 🎨 **三种风格**：种草、痛点、权益价格
- 🔤 **字数控制**：自动、50-100字、100-150字
- 📊 **字段校验**：智能必填项检查与错误提示
- 📋 **导出功能**：复制/导出脚本为 txt 文件

## 🛠️ 技术栈

- **HTML5 + CSS3 + 原生 JavaScript**（v0.3.0+）
- ~~React 18 + Vite 5~~（v0.2.x 及之前版本）

## 📦 版本历史

- **v0.3.1** - 修复标签输入框点击聚焦交互
- **v0.3.0** - 纯 HTML 文件改造，可直接双击打开
- **v0.2.0** - 支持字段启用/禁用与校验机制
- **v0.1.0** - 基础功能完成

## 💡 使用说明

1. **输入商品信息**：在输入框中输入商品名称、描述文本或链接
2. **失焦自动解析**：离开输入框后自动提取并显示建议标签
3. **编辑标签**：点击绿色"+"号添加建议标签，或手动输入
4. **选择设置**：选择脚本风格、字数范围和生成个数
5. **生成脚本**：点击"生成脚本"按钮，获得多个口播文案
6. **复制导出**：复制到剪贴板或导出为 txt 文件

# 页面 UI / 交互 PRD（当前版本）

本文档仅描述“当前页面”的产品 UI 元素与交互逻辑，面向产品与设计，不涉及技术实现、数据结构或团队流程。

## 页面结构（低保真原型）
- 顶部标题：`脚本生成与裂变工具`。
- Panel：`输入商品信息`（单行输入 + 计数 + 加载状态）。
- Panel：`产品信息`（两列网格，含名称/卖点/人群/痛点/促销/场景）。
- Panel：`选择脚本风格`（风格选择、字数选择、生成个数、生成按钮、进度条）。
- 结果区：脚本卡片列表（结构标签、正文、复制/导出）。

## 模块与元素规范

### 输入商品信息（必看）
- 输入框：`#raw-input`，placeholder `请输入商品信息`。
- 计数：右下方显示 `X / 200 字`，随输入实时更新；超过 200 添加红色错误边框。
- 触发解析：仅“失焦”触发；与上次内容相同不重复触发。
- 加载状态：展示旋转图标；解析完成后才显示建议标签（各模块下方）。

### 产品信息（两列网格）
- 布局：`grid-template-columns: 1fr 1fr; gap: 12px;`。
    - 左列：`产品名称`、`产品卖点（主/副）`、`适用人群`。
- 右列：`用户痛点`、`促销折扣`、`适用场景`。

#### 产品名称（必填）
- 单行输入；实时计数 `X / 30 字`；超过 30 显示错误边框。
- 必填徽标：`必填` 常驻；生成前校验非空。

#### 卖点输入（chips + 建议）
- 主卖点（必填）：标签输入组件（见下文组件规范），总字数上限 50。
- 副卖点（选填）：有独立“启用”开关；关闭后不可编辑且不显示建议；字数上限 50。
    - （已移除）自定义卖点。

#### 适用人群（选填，最多 1 项）
- 标签输入组件；最多保留 1 个 chip；字数上限 20。
- 行为：再次添加会替换现有选择（包含点击建议和回车提交）。

#### 用户痛点（模板联动必填）
- 当脚本风格选择 `痛点（pain）` 时，必填（至少 1 项）。
- 标签输入组件；字数上限 50；支持建议标签。

#### 促销折扣（模板联动必填）
- 当脚本风格选择 `权益价格（benefit_price）` 时，必填（至少 1 项）。
- 标签输入组件；字数上限 50；支持建议标签。

#### 适用场景（选填）
- 标签输入组件；字数上限 50；支持建议标签。

### 标签输入组件（统一规范）
- 组成：
  - 输入区域内部展示已添加 chips（绿色/可删除，带 `×`）。
  - 输入框 placeholder：`输入后按回车添加`；当已有内容时自动隐藏。
  - 建议区域：下方展示绿色建议 chips，点击可加入；加载中不展示建议。
- 提交方式：
  - `Enter` / `，` / `,` / `；` / `;` 分隔提交；`blur` 时自动解析当前输入。
  - IME 兼容：中文输入法合成阶段按 `Enter` 不提交，避免截断（合成结束后正常提交）。
- 去重与替换：
  - 同类标签去重；重复点击建议不新增。
  - 人群模块最多 1 项，新增将替换现有项。
- 建议可见性：
  - 已加入后建议 chips 仍保持可见，不做过滤或隐藏（点击后若重复则不变）。
- 计数与限制：
  - 在输入组件右下方或附近显示总字数计数，如 `已用 X / 50 字`（人群为 `20`）。
  - 达到上限后阻止新增；维持建议可见；输入框显示错误态。
- 删除：点击 chip 上的 `×` 即时移除并更新计数。

### 风格与生成设置
- 脚本风格（下拉）：`种草` / `痛点` / `权益价格`。
- 字数（单选）：`自动` / `50-100字` / `100-150字`。
- 生成个数（单选）：`3` / `5` / `8`。
- 生成按钮：`生成脚本`。
- 进度：按钮下方显示进度条与文案（`正在生成...`/`已完成`）。

## 校验与提示（生成前）
- 动态必填：
  - 产品名称：必填。
  - 主卖点：必填。
  - 痛点：当风格为 `痛点` 必填。
  - 促销：当风格为 `权益价格` 必填。
- 失败反馈：
  - 顶部右侧弹出非阻塞通知（约 2.2 秒自动消失）：`还有必填项未填写，请补充后再生成`。
  - 对应输入框红色高亮；不展示下方长错误文案。

## 生成与结果
- 每条脚本卡片：
  - 头部：`脚本N` + 操作区（`复制` / `导出`）。
  - 标签：结构标签 chips（绿色）。
  - 正文：脚本文本。
- 操作：
  - 复制：点击后弹出成功通知。
  - 导出：文件名为 `产品名-序号.txt`。

## 文案与细节统一
- Panel 标题：`📥 输入商品信息`、`📦 产品信息`、`🎨 选择脚本风格`、`🔤 字数`、`🧩 生成个数`。
- 字段徽标：`必填` / `选填`（痛点/促销随模板联动）。
- 人群字段附文案：`最多 1 项`。
- 输入引导：统一使用 `输入后按回车添加`。
- 计数文案：`X / 200 字`（原始输入）、`X / 30 字`（产品名称）、`已用 X / 50 字`（标签组件，部分为 20）。

## 交互流程示例（从零到生成）
1) 在 `输入商品信息` 填写产品文本 → 失焦触发解析 → 显示加载 → 加载结束后各模块出现建议 chips。
2) 在 `产品名称` 填写名称（≤30 字）。
3) 在 `主卖点` 输入若干关键词，回车或逗号提交，或直接点击建议 chips 加入（占用总字数，不重复）。
4) 可按需启用 `副卖点`，方式同上；可在 `适用人群` 选择 1 项（新增替换旧值）。
5) 若选择 `痛点` 风格，则在 `用户痛点` 至少加入 1 项；选择 `权益价格` 风格，则在 `促销折扣` 至少加入 1 项。
6) 选择 `字数` 与 `生成个数` → 点击 `生成脚本` → 进度条运行 → 生成完成显示卡片，可复制/导出。

## 验收要点
- 解析只在失焦触发且内容变化时发生；加载中不展示建议。
- 格式与计数实时更新；达到上限停止新增并显示错误态。
- 中文 IME 合成阶段按 `Enter` 不提交；合成结束后正常提交。
- 建议 chips 保持可见；已添加项不被隐藏或删除。
- 动态必填规则正确阻止生成并给出统一提示。
